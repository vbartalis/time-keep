# No contributions to external projects

Never suggest, let alone open, PRs, issues or patches against third-party projects
(plugin repos, dependencies, upstreams). Extending or fixing external tooling for this
repo's needs is done by local mirror, wrapper or fork-in-repo, never by upstreaming.

**Why:** operator, 2026-08-23: "no pr and similar shit. we dont want to contribute to
a project with 100k+ stars. thats just polluting it. dont suggest these things again."

**How to apply:** when external tooling falls short, present only local options. The
word "upstream" should not appear in a proposal.
